# DEBUGGING — систематическая отладка (адаптация systematic-debugging)

## Цикл (по порядку, без пропусков)
1. Воспроизведение: шаги, условия, частота. Нет воспроизведения — нет фикса, только гипотезы.
2. Evidence: логи, значения, строки кода (файл:строка). Отдельно факты, отдельно предположения.
3. Гипотеза: одна главная причина + как её проверить (а не «попробовать поменять»).
4. Минимальное исправление: smallest diff; запрещены попутные рефакторинги и «заодно».
5. Перепроверка: тот же сценарий воспроизведения + регрессия соседних систем.
6. Запись: root cause и фикс — в CHANGELOG.md форматом из RULES.md.

## Запрещено
- Случайные правки («а вдруг поможет») без гипотезы и проверки.
- Несколько одновременных изменений при поиске причины.
- Удаление диагностических логов до подтверждения пользователя.
