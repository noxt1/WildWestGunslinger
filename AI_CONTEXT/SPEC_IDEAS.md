# SPEC IDEAS — применимые идеи Spec Kit (без установки, workflow не заменяется)

WWG workflow остаётся: АНАЛИЗ → ПЛАН → СОГЛАСОВАНИЕ → ИМПЛЕМЕНТАЦИЯ → ПРОВЕРКА → ДОКАЗАТЕЛЬСТВА → CONFIRMED.

1. constitution/check: перед Планом сверяться с RULES.md + ARCHITECTURE.md как с «конституцией»;
   противоречие = стоп и вопрос пользователю, а не молчаливое отклонение.
2. implement → converge: после ИМПЛЕМЕНТАЦИИ агент сам сверяет результат с Планом и дописывает
   оставшуюся работу как новые пункты (не считая готовым); Converged = всё из Плана покрыто evidence.
   Финальное слово всё равно за пользователем (CONFIRMED).
3. bug-assess → fix → test: багфикс в три отдельных шага — (а) диагноз с evidence и root cause,
   (б) минимальный фикс, (в) тест исходного сценария. Без смешивания в одном проходе.
